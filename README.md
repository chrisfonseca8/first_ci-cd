# First CI/CD

A minimal Node.js HTTP app written in TypeScript.

## Run in development

```sh
npm install
npm run dev
```

Open `http://localhost:3000/home/welcome` to receive the plain-text response `welcome to first cd/cd `.

## Build and run

```sh
npm run build
npm start
```

Set the `PORT` environment variable to use a port other than 3000.
